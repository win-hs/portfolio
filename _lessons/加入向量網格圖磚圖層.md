# 如何加入向量(Vector)、網格(Raster)、圖磚(WMTS/WMS)圖層

<details markdown="1">
<summary>如何加入向量(Vector)圖層</summary>

![]({{ site.baseurl }}/assets/img/lessons/B03-01.png)
1.`Layer` -> `Add Layer` -> `Add Vector Layer`

<br>

![]({{ site.baseurl }}/assets/img/lessons/B03-02.png)
2.`Browse` -> 選擇檔案位置 -> `Add`

</details>



<details markdown="1">
<summary>如何加入網格(Raster)圖層</summary>

![]({{ site.baseurl }}/assets/img/lessons/B03-03.png)
1.`Layer` -> `Add Layer` -> `Add Raster Layer`

<br>

![]({{ site.baseurl }}/assets/img/lessons/B03-04.png)

2.`Browse` -> 選擇檔案位置 -> `Add`

</details>



<details markdown="1">
<summary>如何加入圖磚(WMTS/WMS)圖層</summary>

![]({{ site.baseurl }}/assets/img/lessons/B03-05.png)
1.`Layer` -> `Add Layer` -> `Add WMS/WMTS Layer`

<br>

![]({{ site.baseurl }}/assets/img/lessons/B03-06.png)
2.在跳出的窗口點擊 `New`

<br>

![]({{ site.baseurl }}/assets/img/lessons/B03-07.png)
3.`Name`中可以取自己記得的名字，`URL`的部分則貼上希望介接的WMS/WMTS網址。
本次以國土測繪圖資服務雲WMTS服務為例，網址為：http://wmts.nlsc.gov.tw/wmts

<br>

![]({{ site.baseurl }}/assets/img/lessons/B03-08.png)
4.完成後，再按`Connect`

<br>

![]({{ site.baseurl }}/assets/img/lessons/B03-09.png)
5.選取自己想要的圖層，再按`Add`就完成了。

* 延伸閱讀：[其他WMTS/WMS介接網址]({{ site.baseurl }}/qgis/學習資源開放圖資與小工具整理/)
<br>
<br>
<br>

QGIS Version：QGIS 3.10.12
Date: 20201208

</details>
