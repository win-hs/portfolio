# 常見Q&A


<details markdown="1">
<summary>Q：我應該下載哪種版本的QGIS？</summary>

A：
* 在[QGIS下載網頁中](https://www.qgis.org/en/site/forusers/download.html)，安裝檔可分為Windows、macOS及Linux三種作業平台，請依照你自己電腦的作業平台選擇合適的安裝檔。
* 安裝檔會有兩種版本，分別為最新版本(Latest release)及最穩定版本 (Long term release repository)，最新版本有更多新的功能，但是也可能會有Bug，若無特殊需求，一律建議下載最穩定版本即可。

</details>



<details markdown="1">
<summary>Q：為什麽我的屬性表中的中文字體會是亂碼？</summary>

A：
* 在電腦語言中，英文與中文有不同的編碼方式(Encoding)，而QGIS預設的編碼方式通常無法正常顯示中文字母，因此會出現亂碼。所以需更改圖層的文字編碼。
* 右鍵圖層選擇`Properties` -> `Source` -> `Data Source Encoding` 中選擇合適的編碼。臺灣常見的中文編碼為UTF-8與Big-5。
* 或參考[如何更改圖層的文字編碼 (Encoding)]({{ site.baseurl }}/qgis/更改圖層的文字編碼/)

</details>



<details markdown="1">
<summary>Q：為什麽我工具列中的功能都不見了？</summary>

A：
* 到`Plugins` -> `Manage and Install Plugins` -> 把 `Processing` 功能打勾。  

</details>
