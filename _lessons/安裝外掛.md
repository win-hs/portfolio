# 如何安裝外掛(Plugins)
QGIS是開源(Open Source)軟體，除了軟體自帶的工具外，也開放使用者自行編寫工具，擴充更多的功能。這些使用者創作的工具都可以在QGIS的Plugins安裝工具中下載。

下面以安裝QuickMapServices這個外掛為例：
![]({{ site.baseurl }}/assets/img/lessons/B10-01.png)
1.點選`Plugins` -> `Manage and INstall Plugins`

<br>

![]({{ site.baseurl }}/assets/img/lessons/B10-02.png)
2.在搜尋框搜尋并安裝 `QuickMapServices` 外掛

<br>

![]({{ site.baseurl }}/assets/img/lessons/B10-03.png)
3.`QuickMapServices`的外掛就會出現在`Web`選單下
###### 注：每種外掛安裝後出現的位置都會不太一樣。
