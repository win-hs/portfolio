# 地圖排版加入經緯度格線
![]({{ site.baseurl }}/assets/img/lessons/S03-01.png)
1.在地圖輸出排版頁面，點選`Item Properties` -> `Grids` -> `+` -> `Modify Grid`

<br>

![]({{ site.baseurl }}/assets/img/lessons/S03-02.png)
2. 
* `CRS`為格線參考座標系統，如果要製作經緯度格線就用經緯度的座標系統（WGS84），如果要製作二度分帶的格線就用二度分帶的座標系統（TWD97TM2），本次以經緯度格線做示範。
* `Interval`為格線間隔單位，這裏選`Map Unit`，意思是以“度”為單位。
* `X`、`Y`為XY軸格線的距離間隔，這裏都填上`1`，意思是XY軸格線的距離間隔都是“1度”。

<br>

![]({{ site.baseurl }}/assets/img/lessons/S03-03.png)
3.把`Draw Coordinates`打勾，格線旁就會出現格線對應的經緯度數字。
