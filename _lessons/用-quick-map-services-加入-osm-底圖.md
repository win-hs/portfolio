# [Quick Map Services]如何把OpenStreetMap(OSM)底圖加入QGIS中
}
> <h3>什麼是 OpenStreetMap</h3>
> OpenStreetMap (開放街圖，簡稱OSM) 是自由而且開源的全球地圖，於2004年由英國的 Steve Coast 發起，採用類似 Wiki 的協作編輯以及開放的授權與格式。 OSM 的地圖由像你一樣的使用者繪製。因為來自一般的使用者，所以內容相當多元。資料的來源可能根據手持GPS裝置、航照圖以及其他自由內容，甚至是單靠使用者由於對本地的認識而得。雖然不全是經過專業訓練的人士，但可以產生接近專業地理資訊水準的地圖。 地圖以開放資料庫授權 (ODbL)方式授權，可以日常生活、導航、學術、甚至商業應用。(文字說明來自 OpenStreetMap 台灣)
<br>

![]({{ site.baseurl }}/assets/img/lessons/S02-01.png)
1.在搜尋框搜尋并安裝 `QuickMapServices` plugin
<br>

![]({{ site.baseurl }}/assets/img/lessons/S02-02.png)
2.點選`Web` -> `QuickMapServices` -> `OSM` -> `OSM Standard`


<div class="callout" markdown="1">

❕ 此檔案類型為網絡圖磚（WMTS）為圖片檔，無法進行任何資料的下載或分析。

</div>
