# 只輸出選擇的圖徵(Features)/圖層(layer)
例如，我們只想要屏東市範圍的圖徵，但是只能下載到完整臺灣的圖層，這時候就能用這個功能。

<br>

![]({{ site.baseurl }}/assets/img/lessons/B12-01.png)
1.先把完整臺灣界線的圖層載入。

<br>

![]({{ site.baseurl }}/assets/img/lessons/B12-02.png)
2.點選`Select Features by single click`功能

<br>

![]({{ site.baseurl }}/assets/img/lessons/B12-03.png)
3.右鍵圖層 -> `Export` -> `Save selected Features as`

<br>

![]({{ site.baseurl }}/assets/img/lessons/B12-04.png)
4.選擇檔案格式、檔名、座標格式（CRS），記得要將`Save only selected Features`打勾，然後按`OK`

<br>

![]({{ site.baseurl }}/assets/img/lessons/B12-05.png)
5.完成後就會出現一個只有屏東縣範圍的新圖層。
