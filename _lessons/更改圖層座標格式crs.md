# 更改圖層座標格式(CRS)
![]({{ site.baseurl }}/assets/img/lessons/B04-01.png)
1.右鍵圖層 -> `Export` -> `Save Features as`

<br>

![]({{ site.baseurl }}/assets/img/lessons/B04-02.png)
2.座標系統CRS欄位選擇想要更改的座標格式，再按`ok`即可。
